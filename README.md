# Resume Fit Studio

A browser-based resume editor. Upload a `.docx` file, adjust typography and the usable page area, fit the content to one page, and export a PDF.

The Word file is processed in the browser and is not uploaded to a server. Complex layouts, graphics, and custom Word formatting may need touch-ups after import.

## GitHub Pages

This repository contains a static site and a GitHub Actions workflow that deploys it from `main`. In repository **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. The workflow publishes the repository root; no build step is required.
